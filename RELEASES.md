# Release Notes

## How to add a release entry

When you ship a version, prepend a new block at the top of this file (above all others) using this template:

```markdown
## 🟩 **vX.Y.Z**
📅 *Release date: YYYY-MM-DD*
🔖 Commit: `<short-sha>`
👤 Author: @BielinskiLukasz

### **What's Changed**
- One-sentence summary of the milestone theme.

### **Added**
- Feature or capability that is new.

### **Changed**
- Existing behaviour that was modified.

### **Fixed**
- Bug or regression that was resolved.

### **Full Changelog**
**Full Changelog**: <repo-url>/compare/vPREV...vNEXT

---
```

**Version badge key:**
- 🟩 stable / milestone release
- 🟧 patch / bugfix release
- 🟦 minor feature release
- 🟨 documentation / housekeeping release
- 🟫 initial / experimental release
