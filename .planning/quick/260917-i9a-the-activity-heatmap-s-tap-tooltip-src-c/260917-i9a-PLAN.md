<objective>
Fix the Activity heatmap's tap tooltip (`src/components/Charts/ActivityHeatmap.tsx`) so it can never render below/behind the fixed bottom nav (`src/components/Layout.tsx`). Purpose: Make the heatmap's tap tooltip reliably visible for every tap position, closing a real UX bug and unblocking the pending H2 UAT test ("Heatmap cell tap tooltip") in Phase 02's UAT plan.
