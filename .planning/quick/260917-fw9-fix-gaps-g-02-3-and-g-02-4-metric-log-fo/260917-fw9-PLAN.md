<objective>
Fix gaps G-02-3 and G-02-4 from 02-UAT.md: on date selection in a metric log form, Dexie must be checked for an existing entry on that date. Reading the six form components shows the "entry exists for this date -> load it into the editable field, mark form as editing" half of this behavior (G-02-4) is ALREADY implemented identically in all six forms (WeightForm.tsx, SleepForm.tsx, StepsForm.tsx, WaterForm.tsx, HeartRateForm.tsx, TemperatureForm.tsx) — each form's load effect already queries by date and populates the field(s) plus an editingId/isEditing flag so Save updates rather than duplicates. This plan adds that missing fallback query (reusing the exact `orderBy("date").reverse().first()` pattern already used in `MetricTile.tsx`) to all six forms, and updates 02-UAT.md to mark both gaps resolved.
