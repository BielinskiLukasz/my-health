## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| `useRegisterSW()` tuple destructured as boolean | G-02-1 — see commit `6eef7b9` and `src/components/UpdatePrompt.tsx` | advisory | Always destructure PWA register hooks per their documented tuple shape |
| Fixed-position element inside bottom-nav band | G-02-2 (Log FAB) and the heatmap tooltip nav-clip fix both hit this — a fixed-position element with insufficient bottom offset or a z-index tied with `Layout.tsx`'s nav (`z-50`, later in DOM) gets visually clipped/click-intercepted | advisory | Any new fixed-position UI on screens with the bottom nav needs an offset clear of its ~64px band AND a z-index that wins the DOM-order tie (nav is `z-50`) |
| Fallback-prefill contaminating historic dates | A "no entry for this date → use most recent value" fallback must be gated on the selected date being *today* — otherwise backfilling old dates silently borrows an unrelated value (this bit us once already, commit `b436efa` fixed it) | blocking | Any future "prefill from most recent" logic must check `currentDate === todayISO()` before applying |
| Un-rounded computed values reaching chart Y-axis ticks | BMI (`weight/height²`) and Y-axis domain formulas (`dataMax + N`) can produce long recurring decimals that Recharts renders verbatim as tick labels if no `tickFormatter` is set | advisory | Any new numeric YAxis needs a `tickFormatter` (see `src/utils/axisTick.ts`'s `formatAxisTick`) unless the data is guaranteed to be a clean integer (steps/water counts) |
