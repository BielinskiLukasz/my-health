## Copywriting Contract

### Primary CTA

| Element | Copy |
|---------|------|
| Log form submit | "Log [Metric]" — context-aware per form (e.g., "Log Weight", "Log Sleep", "Log Steps", "Log Water", "Log Heart Rate") |
| Log tab metric picker item | "[Metric] — tap to log" (implicit action) |
| Dashboard tile | Tap opens log form pre-filled (no label needed) |

### Empty States

| Context | Heading | Body | Next Step |
|---------|---------|------|-----------|
| No entries for a metric | "No [metric] logged yet" | "Tap the tile to add your first entry." | Dashboard or Log tab open form |
| Metric not logged today | N/A (tile shows last value + "not logged today" tag) | Implicit in tile state (D-11) | Tap to log today's value |

### Error States

| Context | Message | Recovery |
|---------|---------|----------|
| Save fails | "Failed to save [metric]. Please try again." | Retry button or re-tap Save |
| Validation error (e.g., future date) | "Cannot log future dates. Select today or an earlier date." | Correct field, retry |
| Validation error (e.g., empty field) | "[Field] required. Please enter a value." | Fill field, retry |

### Destructive Actions

| Action | Confirmation Text |
|--------|-------------------|
| Delete weight entry | "Delete this weight entry? This cannot be undone." |
| Delete sleep entry | "Delete this sleep entry? This cannot be undone." |
| Delete steps entry | "Delete this step count? This cannot be undone." |
| Delete water entry | "Delete this water entry? This cannot be undone." |
| Delete heart rate entry | "Delete this heart rate entry? This cannot be undone." |

Modal button labels: "Delete" (destructive, red) and "Cancel" (secondary).

### Toast Notifications

| Event | Duration | Copy |
|-------|----------|------|
| Entry saved | 2s auto-dismiss | "Saved ✓" or "[Metric] saved" |
| Entry deleted | 2s auto-dismiss | "Deleted ✓" |
| Error | 4s or manual dismiss | "Failed to save. Try again." |

## Navigation & Layout

### Bottom Tab Bar

3 tabs only, no additional navigation chrome:

| Tab | Icon | Role |
|-----|------|------|
| Home | house / dashboard | Dashboard snapshot — DASH-01 |
| Log | plus / pencil | Metric picker list — D-02 |
| Settings | gear / cog | User settings (height, dark mode toggle, about, etc.) — UX-04 |

**Active indicator:** Tab icon filled + metric accent color (if applicable). Inactive: outline icon + secondary text color.

**Layout:** Sticky to bottom, full width, equal 1/3 space per tab.

### Dashboard Layout (Home Tab)

- **Header:** Date (e.g., "Wednesday, Sep 3") — 20px semibold, primary text
- **Grid:** 2 columns, equal width, metric tiles in order: Weight, Sleep, Steps, Water, Heart Rate
- **Arrangement:** 2+2+1 (last tile full-width for visual balance)
- **Padding:** 16px page padding (md), 8px gap between tiles
- **No extra UI:** No "log missing metrics" banner, no AI insights, no scrollable sections

### Log Form Layout (Log Tab → Metric)

- **Header:** "[Metric] for [date]" — 20px semibold
- **Date picker:** Tap-to-open, defaults to today, blocks future dates (D-09)
- **Input fields:** Native `input type="number"` with appropriate step (e.g., 0.1 for weight)
- **Labels:** 14px regular, above or left of input (mobile: above)
- **CTA:** "Log [Metric]" button (e.g., "Log Weight"), full-width on mobile, md spacing below
- **Delete button:** Only shows if editing existing entry; secondary destructive style (red, outline)

### Metric Tile (Dashboard Card)

Two variants per D-10 and D-11:

**Variant A: Logged Today**
- Metric name: 14px uppercase tracking, secondary text (Label role), top-left
- Value: 32px semibold, primary text, center-left
- Unit: 14px regular, secondary text, right of value
- Accent bar: 3px left edge in metric color
- Background: #111111, rounded-2xl (16px), padding 16px

**Variant B: Not Logged Today**
- Metric name: 14px uppercase tracking, secondary text (Label role), top-left
- Value (dimmed): 32px semibold, opacity-50, center-left
- Last date: 14px regular, secondary text (Label role), under value (e.g., "Sep 2")
- "Not logged today" tag: 14px uppercase tracking, #27272A background, 4px padding, pill shape
- Accent bar: 3px left edge in metric color (always visible, not dimmed)
- Background: #111111, rounded-2xl (16px), padding 16px

## Sleep-Specific UX (D-06)

Sleep form includes two time pickers:

- **Bedtime:** Time input, formatted as HH:MM (e.g., 23:30)
- **Wake time:** Time input, formatted as HH:MM (e.g., 07:15)
- **Duration (auto-calculated):** Displayed inline as "7h 45m", readonly, updated on input change
- **Next-day handling:** If wake time < bedtime, duration calculation assumes next-day wake (e.g., 11 PM → 7 AM = 8h)
