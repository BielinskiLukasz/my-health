## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub Actions runner → GitHub Pages | Built artifacts pushed from CI runner to gh-pages branch; GITHUB_TOKEN scoped to this repository |
| public internet → GitHub Pages URL | App is publicly accessible; all data remains local in the user's browser |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | GitHub Actions supply chain (action versions) | medium | mitigate | Pin all GitHub Actions to specific major version tags (v4) rather than @latest or @main; reduces risk of compromised action hijacking the build |
| T-03-02 | Information Disclosure | Public GitHub Pages URL | low | accept | By design — app is a public static PWA; no user data is in the deployed files; all health data is in the user's local IndexedDB |
| T-03-03 | Elevation of Privilege | GITHUB_TOKEN write permission | low | mitigate | Workflow declares `permissions: contents: write` at the job level (least privilege — only contents write needed for gh-pages push); no other permissions granted |
| T-03-SC | Tampering | peaceiris/actions-gh-pages action | high | mitigate | Use @v4 tag (stable release); review action source at https://github.com/peaceiris/actions-gh-pages before first use; this is a widely-used (10M+/month) trusted action |
</threat_model>
