    CREATE src/components/Log/TemperatureForm.tsx.
    Model exactly on HeartRateForm.tsx but adapted for temperature:
    - State: value (string), editingId (number | undefined), deleteDialogOpen (boolean), isLoading (boolean)
    - On mount / currentDate change: query `db.temperatures.where("date").equals(currentDate).toArray()`. If entries exist, pick most recent by timestamp. Set value = mostRecent.celsius.toFixed(1), editingId = mostRecent.id.
    - Input: type="number" step="0.1" min="35" max="42" required placeholder="e.g. 36.5"
    - Label: "Temperature (°C)"
    - Submit (new): `db.temperatures.add({ date: currentDate, celsius: parseFloat(value), timestamp: new Date().toISOString() })`
    - Submit (editing): `db.temperatures.update(editingId, { celsius: parseFloat(value), timestamp: new Date().toISOString() })`
    - Delete: `db.temperatures.delete(editingId)`
    - Delete dialog text: "Delete this temperature entry? This cannot be undone."
    - Button labels: "Log Temperature" / "Update Temperature"
    - Toast on save: "Saved"; on delete: "Deleted"; on error: "Failed to save temperature. Please try again."
    - After save or delete: navigate("/log")

    UPDATE src/components/Log/LogScreen.tsx.
    Import TemperatureForm. Add "temperature" to the metrics const array. Add dispatch:
    `if (metric === "temperature") return <TemperatureForm />`

    UPDATE src/components/Dashboard/MetricTile.tsx.
    Add `case "temperature":` to the loadTileData switch (after `case "heartRate":`):
    ```
    case "temperature": {
      const todayEntries = await db.temperatures
        .where("date")
        .equals(currentDate)
        .toArray()
      if (todayEntries.length > 0) {
        const avg = todayEntries.reduce((sum, e) => sum + e.celsius, 0) / todayEntries.length
        return { variant: "a", value: avg.toFixed(1) }
      }
      const last = await db.temperatures.orderBy("date").reverse().first()
      if (last) {
        return { variant: "b", value: last.celsius.toFixed(1), lastDate: last.date }
      }
      return { variant: "c", value: "" }
    }
    ```
    Also import `Temperature` from schema if needed for TypeScript (Dexie table is already typed).
