### On-Track Status Colors (Phase 3 new layer)

Target progress is color-coded using the following statuses. Displayed as a status badge (14px label, rounded pill, with icon/emoji) next to the chart header or above the target progress bar on dashboard tiles:

| Status | Color | Hex | Tailwind | Usage |
|--------|-------|-----|----------|-------|
| Green (on track) | Emerald | #10B981 | `bg-emerald-500` / `text-emerald-400` | User is on pace to hit target; threshold: ≤ tolerance of target value (D-10) |
| Yellow (off track) | Amber | #F59E0B | `bg-amber-500` / `text-amber-400` | Off track but still recoverable; threshold: within 2× tolerance but > tolerance (D-10) |
| Red (far off) | Red | #EF4444 | `bg-red-500` / `text-red-400` | Not on pace; threshold: > 2× tolerance or wrong direction (D-10) |
| Grey (insufficient data) | Gray | #6B7280 | `bg-gray-500` / `text-gray-400` | Fewer than 7 days of data; no status shown yet (D-11) |

**Thresholds (numeric tolerances determined during planning; planner to propose sensible defaults per metric):**
- Weight: ±0.5 kg (green = within 0.5 kg of projected pace; yellow = 0.5–1 kg; red = >1 kg off)
- Sleep: ±0.5 h (green = within 30 min; yellow = 30–60 min; red = >1 h off)
- Steps: ±500 steps/day (green = within 500; yellow = 500–1000; red = >1000 off)
- Water: ±200 ml/day (green = within 200 ml; yellow = 200–400 ml; red = >400 ml off)
- Heart Rate: ±3 bpm (green = within 3 bpm of ceiling; yellow = 3–6 bpm; red = >6 bpm off)
- Exercise proxy: weekly count (green = hit weekly target; yellow/red = below weekly target by 1–2 / >2 sessions)

|---------|-------|

## UI Considerations

### State Coverage — Phase 3 Targets, Streaks & Personal Bests

Phase 3 introduces new UI states on existing surfaces (Dashboard tiles, chart screens) and one new surface (exercise proxy tile).

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| empty | No target set (metric tile) | ✅ covered | Tile renders as Phase 1/2 (value + sparkline only); no progress bar or streak shown; no status badge. |
| empty | No entries logged yet (target metrics) | ✅ covered | Chart screen shows "Not enough data yet" status badge; no pace/color shown; target reference line visible but no data points (D-11). |
| empty | Exercise proxy tile — no sessions logged | ✅ covered | Tile shows "0/[target] this week" + toggle button; streak shows "0 week streak" or "0 days" if no target set; no status color until target is set. |
| loading | Target data fetch on chart mount | 🧪 backstop | Chart loads target reference line and status badge during IndexedDB read; no loading indicator shown (read latency <50ms expected per project constraints). |
| loading | Pace calculation in-flight | 🧪 backstop | Status badge shows "Not enough data yet" (grey) during re-calculation if user logs new entry; badge updates when calculation completes. |
| partial | 6 days of data logged (target active) | ✅ covered | Status badge shows "Not enough data yet" (grey) — no colored status until 7 days is reached (D-11). |
| partial | Target set, some data but not yet on pace | ✅ covered | Status badge shows "Off track" (yellow or red); progress bar shows current % toward target; streak shows "0" if not yet qualifying days. |
| populated | 7+ days logged, target met | ✅ covered | Status badge shows "On track" (green); progress bar shows % complete; streak shows "N day streak" (resets to 0 if a day is missed per D-16). |
| populated | Personal best logged | ✅ covered | "🏆 Personal best!" badge appears on both dashboard tile (for that metric/day) and chart screen (above chart or in stat area). |
| populated | Exercise proxy — weekly target met | ✅ covered | Tile shows "4/4 this week" + toggle; status badge shows "On track" (green); streak shows "N week streak". |
| overflow | Target value very large (e.g., 99999 steps) | 🧪 backstop | Progress bar label shows "[large#]/[large#]" — confirm no label overflow on 320px screen at 14px font. |
| overflow | Streak count ≥ 100 days | 🧪 backstop | Streak label "100 day streak" fits on tile at 14px without truncation on 320px minimum width. |
| overflow | Very long target date label | ✅ covered | Chart header shows "Target: [value] by [date]" — date always ISO YYYY-MM-DD (11 chars); no overflow. |
| long-text | Personal best context (exercise) | 🧪 backstop | "🏆 Personal best!" badge is fixed width; confirm it doesn't wrap on 320px screen. |
| zero-one-many | Multiple targets across 6 metrics | ✅ covered | Each metric tile shows its own progress bar and status badge independently; all visible on dashboard in same 2-column layout as Phase 2. |
| zero-one-many | Exercise proxy — weekly session count | ✅ covered | Tile shows "N/[target] this week" for 0, 1, 2, ..., many sessions; toggle behavior is per-day (D-07). |

## Visual Treatments (New in Phase 3)

### Progress Bar on Dashboard Tiles

Placed above or below the metric value, **only if a target is set** (D-05):

- **Bar container:** Full width of tile minus padding, 8px height, rounded-lg, bg-zinc-800 (dark mode) or bg-gray-200 (light mode)
- **Bar fill:** Metric accent color (e.g., blue-500 for weight), width = (current_value / target_value) × 100%, rounded-lg, no animation
- **Label:** 14px label (14px font weight 400), placed above or below bar, format "[current]/[target] [unit]" (e.g., "73.2/75 kg")
- **Overflow handling:** If label text overflows, shrink label to 12px or move to separate line below bar

### On-Track Status Badge

Displayed **next to the chart header stat** (D-13, reuses D-04 stat area) and **above the target progress bar on dashboard tiles**:

- **Format:** 14px label (weight 400) in uppercase or title case (e.g., "ON TRACK" or "On track"), with optional emoji/icon
- **Styling:** Rounded pill, 6–8px padding, text color white, background color per status (green/yellow/red/grey)
- **Placement on chart:** Inline with "Avg / Min / Max / Trend" stat row, right-aligned or wrapped to second line if needed
- **Placement on tile:** Above progress bar (if present) or in place of streak if target was just set

### Streak Display

Shown on metric tiles and exercise tile, **only if a target is set** (D-05):

- **Format:** 14px label (weight 400), e.g., "5 day streak" or "2 week streak" (exercise only per D-17)
- **Placement on tile:** Below progress bar, left-aligned, secondary text color (gray-400 in dark mode)
- **Empty state:** If no qualifying days logged, shows "0 day streak" in secondary text (never hidden)

### Personal Best Badge

Shown as an inline badge on both dashboard tile and chart screen when a new PB is reached:

- **Format:** "🏆 Personal best!" (emoji + fixed text)
- **Font size:** 14px (label role)
- **Styling:** Rounded pill, 6–8px padding, text color primary text, background color amber-500 (reserved for highlights) or metric accent color
- **Placement on tile:** Below metric value or streak (stacked vertically)
- **Placement on chart:** Above chart title or in stat row, marked with emoji

### Target Reference Line on Chart

Reuses Recharts `ReferenceLine` component (Pattern from Phase 2 BmiSection):

- **Line style:** Dashed (strokeDasharray="5,5"), 2px width, color = metric accent color (e.g., blue-500 for weight)
- **Label:** Target value displayed on the right edge of the chart, 12px font, metric accent color, e.g., "75 kg"
- **Position:** Y-axis value = target value (or target range min/max for sleep and heart rate per D-04, D-12)

### Exercise Proxy Tile (7th Dashboard Tile)

New tile for exercise-frequency proxy, following the same tile pattern as other metrics:

- **Tile layout:** Same card style as metric tiles (16px padding, rounded-2xl, zinc-900 background, 3px accent bar in metric pink #EC4899)
- **Content:**
  - Metric name: "Exercise" (14px uppercase, secondary text)
  - Count display: "[N]/[target] this week" (20px semibold, primary text) — updates daily
  - Toggle button: "Mark as exercised" or simple checkbox icon, full-width, placed below count (optional text label)
  - Status badge: On-track status (green/yellow/red/grey) based on weekly session count vs. target (D-07)
  - Streak: "[N] week streak" (14px secondary text, per D-17)
- **Interaction:** Tap toggle to mark today (or this week) as having exercised; toggle persists to IndexedDB exerciseLog table (D-01)
- **Empty state:** If no target set, tile shows "Exercise" label + "Set a target to track progress" hint (D-05)

Accessible from `/chart/:metric` screen (D-06):

- **Header:** "Set [Metric] Target" (20px semibold)
- **Inputs:**
  - Target value input: "Goal value" label, 16px font, native `input type="number"` with appropriate step (e.g., 0.1 for weight)

## Pre-Populated Decisions from Phase 3 Context

The following are locked decisions from `/gsd-discuss-phase` (03-CONTEXT.md) and are **not** subject to change during planning:

| Decision | Context Ref | Contract Impact |
|----------|------------|-----------------|
| Exercise proxy as lightweight placeholder (not full training sessions) | D-01 | 7th dashboard tile with boolean/weekly-count toggle; Dexie v3 exerciseLog table |
| Weight target direction inferred (loss or gain) | D-02 | Target form asks for "target value"; direction calculated from comparison to current weight |
| Heart rate target is ceiling (lower is better) | D-03 | Form UX reflects ceiling framing; projected pace uses "<X bpm" language |
| Sleep target is range (around X hours) | D-04 | Target form allows entry of range; on-track status uses proximity to nearest edge (D-12) |
| No target = unchanged tile (Phase 1/2 UI) | D-05 | Tiles without targets show no progress bar, status badge, or streak |
| Targets set from chart screen, not Settings | D-06 | `/chart/:metric` screen has "Set Target" / "Edit Target" CTA; no centralized target list |
| Exercise proxy gets 7th dashboard tile | D-07 | New tile with session count, toggle, status, and streak display |
| Target edits do not reset streak | D-08 | Streak persists across target value/date changes |
| Linear trend for pace calculation (7-day window) | D-09 | Planner proposes trend method; likely simple least-squares fit |
| Red/yellow/green thresholds (D-10) | D-10 | Three tolerance bands per metric; planner proposes defaults (see On-Track Status Colors above) |
| 7-day minimum for colored status (D-11) | D-11 | Fewer than 7 days = grey "Not enough data yet" badge |
| Range/ceiling distance for on-track (D-12) | D-12 | Sleep and HR use proximity to edge, not mid-range; same tolerance logic as point targets |
| Target line + status badge on chart (D-13) | D-13 | Recharts `ReferenceLine` + status badge in stat row |
| Daily entry required for streak (D-14) | D-14 | Day counts only if entry logged AND met target; no grace days |
| Weight "toward goal" signal for streak (D-15) | D-15 | Weight streak checks if value moved toward goal direction vs. previous logged value |
| No grace days for streak (D-16) | D-16 | Any missed day resets streak to 0 immediately |
| Exercise proxy streak is weekly (D-17) | D-17 | Counts consecutive weeks hitting weekly target, not daily |
| Per-metric streaks, no combined (D-18) | D-18 | Each metric-with-a-target shows independent streak |
| Streak shows 1 on first day if qualified (D-19) | D-19 | New target on day N shows "1 day streak" if that day's entry qualifies |
| PB detection spans history + current (D-20–22) | D-20, D-21, D-22 | All 6 metrics get PB detection; flagged on chart + tile; retroactive scan on first use; Temperature excluded |
